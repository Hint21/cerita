# sebuah cerita yang pernah ada

Website personal sebagai hadiah terakhir untuk Alifah.

## Menjalankan lokal
Buka index.html via server statis (python -m http.server) lalu akses http://localhost:8000

## Password akses
Format: 29072026 (tanggal jadian, 29 Juli 2026). Hanya privacy gate, bukan keamanan server.

## Musik
Belum disertakan. Jika ingin menambahkan musik instrumental yang legal (mis. Pixabay Content License), letakkan file di assets/music/ambient.mp3 dan aktifkan pemutar di js/app.js.

## Hosting
Target: GitHub Pages (gratis). Repo: hint21/cerita -> https://hint21.github.io/cerita/

## Aset
44 aset di manifest (31 foto + 12 tangkapan layar + 1 Roblox), dikonversi ke WebP, lazy-loaded. Pada versi final, 30 foto + 8 tangkapan layar digunakan di website (1 foto near-duplicate dan 4 tangkapan layar repetitif dikeluarkan dari penggunaan, file asli tetap aman). Konteks foto tidak diketahui, sehingga tidak diberi caption.
